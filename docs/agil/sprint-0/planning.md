# Sprint 0 — Planning

**Proyecto:** CircleGuard
**Sprint:** DCG Sprint 0
**Periodo:** 1–2 de noviembre de 2026
**Equipo:** Daniela Castaño Moreno, Santiago Alejandro Estrada, Faiber Piedrahita Perlaza y Alejandro Quiñones Caicedo
**Tablero:** [DCG en Jira](https://bomastik-site.atlassian.net/jira/software/projects/DCG/boards/67?filter=&groupBy=none)

## Objetivo

Conformar el equipo, definir el marco ágil y la estrategia de branching, construir el
backlog inicial con historias y criterios de aceptación, y dejar la base de CI/CD e
infraestructura para que el Sprint 1 pudiera entregar el incremento de producto.

## Riesgos planificados

| Riesgo | Mitigación |
|---|---|
| Credenciales y entornos no disponibles | Documentar bootstrap y runbook; secretos fuera del repositorio |
| Backlog ambiguo | AC medibles y revisión por pares antes de iniciar el Sprint 1 |
| Pipeline incompleto | Priorizar el flujo multibranch y dejar los servicios restantes al Sprint 1 |
