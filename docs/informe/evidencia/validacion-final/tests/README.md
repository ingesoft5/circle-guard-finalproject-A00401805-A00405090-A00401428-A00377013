# Pruebas

Reportes JUnit y cobertura archivados por el build `main #68` de Jenkins.

- `junit-<servicio>-<tipo>-TEST-*.xml`: resultados unitarios y de integración de los microservicios.

Los archivos son la salida directa del pipeline, sin edición posterior.
