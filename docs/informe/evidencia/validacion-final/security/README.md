# Seguridad

Reportes Trivy IaC archivados por el build `main #68` de Jenkins:

- `trivy-iac.json`: escaneo agregado.
- `trivy-iac-k8s.json`: manifiestos de Kubernetes.
- `trivy-iac-terraform.json`: configuración de Terraform.
- `trivy-iac.txt`: resumen legible del escaneo.

Los archivos son la salida directa del pipeline, sin edición posterior.
