# Executive Summary — E2.9

CircleGuard is a privacy-oriented contact-tracing and health-monitoring platform built as eight Java 21 / Spring Boot 4.0.10 microservices plus a web client. The final platform runs on a shared academic host with k3d (k3s), Traefik ingress, Kustomize overlays for `cg-dev`, `cg-stage` and `cg-prod`, and a Jenkins multibranch pipeline that takes a change from commit to versioned image and controlled promotion. The design keeps identities in a separate vault, publishes health events through Kafka, and exposes Prometheus metrics, structured logs and OTLP traces without personal data.

**What is actually verified in the final run.** [EJECUTADO] The archived `main #68` result is `SUCCESS`; `build-68-stages.json` records successful Terraform plan/apply, SonarQube Quality Gate, Trivy IaC gate, Docker client and post actions, and `validacion-final/tests/` holds JUnit and coverage reports. Cluster captures under `validacion-final/cluster/` are stamped `20261124T091219Z` and show the three namespaces with deployments, HPA, services and secrets-by-name only. [CÓDIGO EN HEAD] Resilience4j Circuit Breaker + Retry, external configuration and the transactional outbox are implemented with injected-failure tests; the dependency platform is Spring Boot 4.0.10 in `build.gradle.kts`.

**What is not validated as a final-run result.** [FALLO PROBABLE] No Locust HTML/CSV report is archived in `validacion-final/`, and the `E2E` and `OWASP ZAP Security Gate` stages are `NOT_EXECUTED` in the final build. [HISTÓRICO] Earlier PRs (`#93`, `#138`, `#139`, `#174`) and `docs/infra/evidencia/E2.4-E2.5-seguridad.md` document ZAP configuration, Trivy remediation and a local Jaeger smoke test with a synthetic span; observability screenshots show dashboards, rules and alertmanager views. [RIESGO] Those artifacts do not prove that the final run fired alerts, exported an end-to-end trace, or passed a load or DAST gate. No result is reported for those four items; the live demo and the archived scripts are the reproducible path to obtain them.

**Cost position (A9).** Part 1 used four EC2 instances — `cg-tools`, `cg-dev`, `cg-stage` and `cg-prod` — with an estimated monthly cost of **USD 90–150** in total. The laboratory account is blocked, so there is no verifiable invoice to quote; the figure is an estimate, not measured spend. The final report and presentation now use this A9 figure instead of an incompatible equivalent-topology calculation.
