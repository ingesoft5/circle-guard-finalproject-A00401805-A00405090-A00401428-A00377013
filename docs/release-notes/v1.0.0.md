## Alcance

Primera versión semver de la plataforma. Fija la convención de versión para las imágenes del
registro `circleguard-docker` y consolida el empaquetamiento inmutable del núcleo de servicios.

## Cambios

- Empaquetamiento inmutable de `identity-service` y del resto de los servicios núcleo (#30).
- Helpers de semver integrados en el pipeline y biblioteca compartida fijada a `main` para evitar
  deriva entre la librería y el `Jenkinsfile`.
- Proyectos y gates de SonarQube configurados para los servicios incorporados en esta versión.

### Plataforma

- Catálogo de imágenes y variables de entorno por servicio listo para promoción entre ambientes.
